# Quickstart: Exam Builder (Standalone)

## Prerequisites
- Node.js installed

## Setup
1. Define `.env.local`:
   ```env
   GEMINI_API_KEY=your_key_here
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the application:
   ```bash
   npm run dev
   ```
   Navigate to `http://localhost:3000`.

*Note: The Music Academy interface and its routes are completely excluded when running these steps.*
